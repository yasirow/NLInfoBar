# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment,
insults and personal attacks are not tolerated.

Please also respect privacy: do not post anyone's personal information, and do not ask others for theirs. Logs and
screenshots in issues should not contain personal data.

To report unacceptable behaviour, contact the maintainers privately through
[GitHub's private reporting](https://github.com/yasirow/NLInfoBar/security/advisories/new) or by messaging a
maintainer on GitHub. Maintainers may remove comments, issues or contributions that violate this code and may block
repeat offenders.
